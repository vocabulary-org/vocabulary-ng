About

Vocabulary is an open-source vocabulary learning application that brings the simplicity of a paper vocabulary notebook into a modern digital format — with flashcards, spaced repetition, and multi-language support.

Architecture

Frontend

Angular 20 with Angular Material and Bootstrap. Single-page application served via Nginx.

Backend

REST API providing vocabulary management, flashcard review, and user data services.

Authentication

Identity and access management via Keycloak, supporting standard login and Google OAuth.

Infrastructure

Hosted on Hetzner Cloud with Nginx as reverse proxy and TLS termination.
